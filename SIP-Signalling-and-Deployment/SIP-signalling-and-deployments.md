# SIP  (Signaling & Deployment)
## "SIP supports 5 main facets for establishing and terminating multimedia communications:"

- User Location: Determines the location of the target endpoint.

- User Availability: Determines if the target endpoint is available. (If unavailable, SIP returns a specific error message).

- User Capabilities: Determines the media capabilities (e.g., supported codecs) of the target endpoint. This info is conveyed via SDP.

- Session Setup: Establishes a session between the originating and target endpoints.

- Session Management: Manages calls (e.g., transfer, terminate). Allows transparent combination of calls.
